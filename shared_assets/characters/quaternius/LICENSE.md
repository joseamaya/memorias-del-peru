# Quaternius — animaciones UAL2

## Qué se usa

- `animations/UAL2_Prototype.glb`: 11 clips de **Universal Animation Library 2
  (Standard gratuito)**, Quaternius, CC0. Se extraen con
  `pch_ual2_library.py`; no se versiona el paquete completo de 18 MB.

## Licencia

- **Autor:** Quaternius
- **Pack:** Universal Animation Library 2, versión **Standard gratuita**
- **Origen:** https://quaternius.com/packs/universalanimationlibrary2.html
- **Descarga:** `Universal Animation Library 2[Standard].zip`, 18 MB, descargado el 2026-11-17
- **Licencia:** [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- **Clips conservados:** `Idle_No_Loop`, `Farm_PlantSeed`, `Farm_Harvest`,
  `TreeChopping_Loop`, `Hit_Knockback`, `Melee_Hook`, `Melee_Hook_Rec`,
  `Walk_Carry_Loop`, `Sword_Block`, `Yes`, `Chest_Open`.
- **Uso:** `idle_b`, `work` y `hit` de los clips de animación. La versión Source
  de pago no se usa.

## Retirada del elenco UBC

Los cuerpos, caras, ojos, pelo y barba de Universal Base Characters se
retiraron el 2026-11-18 junto con sus GLB, texturas, catálogo y pruebas. El
cuerpo UAL1 de `shared_assets/characters/mannequin/` sigue disponible como
herramienta para los personajes que diseñe la campaña nueva; el elenco que lo
usaba se retiró con la campaña lineal. El documento histórico del elenco UBC
queda en el historial de git.
