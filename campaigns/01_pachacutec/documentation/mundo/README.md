## Regla de trabajo

Ningún sector se construye antes de que este dossier esté aprobado. La geografía se clasifica como **GD** (documentada), **GR** (reconstrucción aproximada) o **GN** (ficción necesaria). Una distancia comprimida, un valle inventado o un paso ficticio se declaran como tales.

## Estado

- La historia, el elenco y el registro histórico de la campaña existen y se conservan.
- La implementación lineal (cinco actos, tres escenarios) está congelada y se usa como banco de pruebas.
- La región de mundo abierto es una **propuesta** que debe validarse con el expediente histórico y el blockout.
